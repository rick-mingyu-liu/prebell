  - **Escaping**: a summary that starts like a list or heading (`-`, `+`, `*`, `#`, `1.`, `1)`) is escaped, every `{` becomes `&#123;` so no `{{` or `{%` reaches Buttondown's template tags, and an unparsable "moved from" date is escaped.
  - **A `digest` message on any day but Friday from 18:00 ET does nothing**, so a stray message can never take the week's slot.
  - **`/api/subscribe` checks `source` again** (`home`, `post`, `about`), as on main, without sending it to Buttondown.
  - **Switch-on order**: the generator first; Rick checks the first Friday draft in Buttondown's preview while there are no subscribers; the web key last, which shows the form. Sent digests appear in Buttondown's public archive by default. In `docs/runbook.md`, "Weekly digest".
